# ADR-003: Заказы без онлайн-оплаты

**Статус:** Принято  
**Дата:** 2026-08-06

## Контекст

Приложение — инструмент дизайн-студии. Оплата товаров и услуг происходит по договору, счёту или офлайн. Нет необходимости в PCI DSS и платёжных шлюзах.

## Решение

Заказ в приложении — **заявка на комплектацию**, а не транзакция с оплатой.

### Статусы заказа

```
оформлен → согласован → собирается → в пути → доставлен
```

### Что есть в MVP

- Корзина (товары, количество, сумма)
- Оформление заказа (адрес, комментарий)
- История заказов и статусы
- Push при смене статуса

### Чего нет

- Интеграция с ЮKassa, CloudPayments и т.д.
- Привязка карт
- Онлайн-оплата в приложении

## Обоснование

- Быстрее MVP (экономия 1–1.5 спринта).
- Проще модерация в App Store / Google Play.
- Соответствует бизнес-процессу студии.

## Последствия

- Оплата вне приложения (менеджер выставляет счёт).
- В будущем можно добавить deep link на оплату, не меняя модель заказа.
