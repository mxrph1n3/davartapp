# Davart CRM

Кабинет комплектации: Master-Detail по клиентам на том же Nest API, что и мобильное приложение.

## Локально

API должен уже работать на `:3000`. Затем:

```bash
cd apps/admin
cp -n .env.local.example .env.local
npm install
npm run dev
```

Открыть http://localhost:3001

Вход — OTP по телефону сотрудника. В mock-режиме код пишется в лог API (`[MOCK SMS]`):

| Роль | Телефон |
|------|---------|
| Комплектатор | `+79009999998` |
| Дизайнер | `+79009999999` |
| Admin | `+79009999990` |

Клиентский номер (`+79001234567`) в CRM не пускает.

## Что внутри

- Слева — клиенты и фильтры: Все / С проектами / С заказами / Мои
- Справа — карточка: Проекты, Документы, Корзина, История, Профиль (включая день рождения)
- Deep link из Telegram: `/clients/{clientId}/orders/{orderId}`

Переменные: `.env.local.example`. Деплой на Reg.ru: [DEPLOY.md](./DEPLOY.md).
